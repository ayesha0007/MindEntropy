MindEntropy AI: Clinical Research Hub
Multidimensional PHQ-9 Analysis using Multi-Entropy Features & Machine Learning

🛠 Project Vision
MindEntropy AI is a professional research prototype designed to advance psychological screening. While traditional PHQ-9 tools rely solely on cumulative scores, this system analyzes the complexity and predictability of patient responses using information theory (Entropy) and Machine Learning (XGBoost logic).

📸 System Walkthrough
1. Research Access Portal
The system begins with a secure gateway designed for authorized personnel.

Developer Note: For evaluation and demonstration purposes, this portal is currently in Easy Access Mode. Any input provided in the Researcher ID and Access Key fields will grant immediate entry to the hub.
